# Restaurant Page

A simple restaurant website built as part of [The Odin Project](https://www.theodinproject.com/lessons/node-path-javascript-restaurant-page) curriculum. All page content is generated with JavaScript, with tab switching between Home, Menu and Contact.

**Live preview:** https://w1ttyy.github.io/restaurant-page/

## Features

- Content created entirely with JavaScript (DOM manipulation)
- Each tab in its own ES module
- Tab switching without page reload, active tab highlight
- Bundled with webpack

## Built with

- HTML, CSS, JavaScript
- webpack, webpack-dev-server, html-webpack-plugin, css-loader, style-loader

## Run locally

```
git clone https://github.com/w1ttyy/restaurant-page.git
cd restaurant-page
npm install
npx webpack serve
```

Then open http://localhost:8080
